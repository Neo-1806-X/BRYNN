# Milestone M0.1: Engineering baseline and walking skeleton

Status: delivered in drop 001 (2026-11-19); **not yet verified by the owner**.

## Goal

Prove the toolchain end to end with the smallest real service: a repository with the ledger and Phase 1 docs, a quality gate that runs the same on your machine and in CI, and a Go API that builds into a hardened container, answers health probes, logs in structured JSON and shuts down gracefully (drain, then stop).

**Out of scope:** database, authentication, any product feature. Those start in M0.2.

## Prerequisites on your computer

Git, Docker with the Compose plugin, `make` and `curl`. Nothing else: Go runs inside a container.

- **Windows:** install WSL2 with Ubuntu, install Docker Desktop and enable its WSL integration. Run every command below in the Ubuntu terminal and keep the repository inside the Linux filesystem (for example `~/brynn`), not under `/mnt/c`.
- **macOS:** Docker Desktop (or Colima) and the Xcode command line tools for `make`.
- **Linux:** Docker Engine with the Compose plugin; add your user to the `docker` group.

## Steps

**1. Check the tools.** Paste any failure to me.

```sh
git --version
docker --version
docker compose version
make --version
curl --version
```

**2. Create the repository.** Use a no-reply email address if you plan to push to GitHub, so your personal address is not published in commit history.

```sh
mkdir -p ~/brynn && cd ~/brynn
git init -b main
git config user.name "Your Name"
git config user.email "you@example.com"
```

**3. Unpack drop 001.** Copy `brynn-drop-001.zip` into your Linux home first (from WSL: `cp /mnt/c/Users/<you>/Downloads/brynn-drop-001.zip ~/`).

```sh
unzip ~/brynn-drop-001.zip -d ~/brynn
ls -a ~/brynn
```

You should see `PROJECT_LEDGER.md`, `Makefile`, `docker-compose.yml`, `apps`, `docs`, `scripts` and `.github`.

**4. Read and review (the veto window).** Read `PROJECT_LEDGER.md` and `docs/phase1/01-technology-selection-report.md`. Give ChatGPT both files plus the review request in ledger Appendix B. Send me its findings; I will triage them. If you or ChatGPT object to Go, say so before step 5.

**5. Run the quality gate.** The first run downloads the Go image and takes a few minutes.

```sh
cd ~/brynn
make check
```

Expected: the last line is `OK`. If it lists unformatted files, run `make fmt` and then `make check` again. I could not run gofmt or the compiler while writing the code, so a formatting or compile finding on the first run is plausible. Paste the **whole** output of any failure.

**6. Start the API and probe it.**

```sh
make up
make smoke
```

Expected `make smoke` output, exactly:

```text
{"status":"ok"}
{"status":"ready"}
{"version":"dev","commit":"unknown"}
```

Also check the error format, which should be a 404 with `Content-Type: application/problem+json`, an `X-Request-ID` header and a JSON body:

```sh
curl -i http://127.0.0.1:8080/nope
```

Optional hardening check (expect `nonroot:nonroot readonly=true`):

```sh
docker inspect --format '{{.Config.User}} readonly={{.HostConfig.ReadonlyRootfs}}' brynn-api-1
```

**7. Look at the logs.**

```sh
make logs
```

Press Ctrl-C to leave. You should see JSON lines such as `"msg":"starting"` and `"msg":"http_request"` with `request_id`, `status` and `duration_ms`.

**8. Prove graceful shutdown.** In one terminal run `make logs`. In another:

```sh
docker compose stop api
docker compose ps -a
```

Expected: the logs show `shutdown_started` then `shutdown_complete` after about five seconds, and the container shows `Exited (0)`.

**9. Clean up and commit.**

```sh
make down
git add -A
git commit -m "chore: foundation drop 001"
```

**10. Push and check CI (recommended).** Create a **private** GitHub repository, push `main`, open the Actions tab and confirm the `ci` workflow is green. If you do not use GitHub, tell me and we will pick another host; the workflow only calls `scripts/check-go.sh` and `docker build`, so it moves easily.

**11. Report back.** Paste: the output of steps 1, 5, 6 and 8; the CI result if you did step 10; and your operating system. I will record it in ledger section 8 and mark M0.1 verified or fix what failed.

## Troubleshooting

- **`golang:1.27` not found.** Run `make check GO_IMAGE=golang:1.26` and change the first line of `apps/api/Dockerfile` to `FROM golang:1.26 AS build`.
- **`docker: permission denied` (Linux).** Add your user to the `docker` group and log in again.
- **`make: *** missing separator`.** An editor turned the Makefile's tabs into spaces. Re-extract the file from the zip.
- **Port 8080 already in use.** Stop the other program, or change the left-hand port in `docker-compose.yml` and the URLs in the Makefile.
- **Windows line endings.** `.gitattributes` forces LF. If you extracted files under Windows tools, delete the folder and re-extract inside WSL.
